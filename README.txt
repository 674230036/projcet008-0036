NPRU Room Booking - อาคาร C (PHP OOP + MySQL)

1) สร้างฐานข้อมูล
- เปิด phpMyAdmin
- Import ไฟล์ database.sql

2) ตั้งค่าฐานข้อมูล
แก้ config/config.php
DB_HOST = localhost
DB_NAME = npru_room_booking
DB_USER = root
DB_PASS = รหัสผ่าน MySQL ของคุณ

3) วางโฟลเดอร์ใน XAMPP
C:\xampp\htdocs\NPRU_RoomBooking

4) เปิด
http://localhost/NPRU_RoomBooking/public/

5) Admin ทดลอง
Username: admin
Password: 1234
