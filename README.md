## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. ระบบสำหรับผู้ใช้งาน (นักศึกษา / บุคลากร)
- 📅 **ปฏิทินแสดงสถานะห้องแบบ Real-time:** แสดงสถานะห้องว่าง กำลังใช้งาน หรือติดจองในแต่ละช่วงเวลา
- 🏢 **รายการห้องเรียนและห้องประชุม อาคาร C (C301 - C310):**
  - แสดงรูปภาพห้องจริง, ความจุผู้เข้าร่วม (Capacity), ชั้นที่ตั้ง, และอุปกรณ์อำนวยความสะดวก (โปรเจกเตอร์, เครื่องปรับอากาศ, ไมค์ลอย ฯลฯ)
  - มีระบบค้นหาห้องและกรองตามประเภท (ห้องประชุม / ห้องเรียน)
- 📝 **ระบบฟอร์มขอจองห้องอัจฉริยะ:**
  - ตรวจสอบความถูกต้องของข้อมูล (Validation) ทั้งรูปแบบอีเมล และจำนวนผู้เข้าร่วมไม่ให้เกินความจุของห้อง
  - **ระบบป้องกันการจองทับซ้อน 100% (Conflict Prevention):** ป้องกันไม่ให้มีการส่งคำขอในช่วงเวลาที่ผู้อื่นจองไว้แล้ว
- 🔔 **ศูนย์การแจ้งเตือนส่วนบุคคล (Notification Center):**
  - แจ้งเตือนทันทีเมื่อคำขอได้รับการอนุมัติ หรือเมื่อฝ่ายอาคารฯ จัดเตรียมห้องเสร็จสิ้น
  - ทำเครื่องหมายว่าอ่านแล้วได้แบบ Real-time
- 📜 **ประวัติการจองและติดตามสถานะ:**
  - ตรวจสอบสถานะคำขอของตนเองได้แบบละเอียด (รอตรวจสอบ -> ผ่านการอนุมัติ -> พร้อมใช้งาน)

### 2. ระบบสำหรับเจ้าหน้าที่และผู้ดูแลระบบ (Admin & Staff Panel)
- 📋 **การอนุมัติแบบ 2 ขั้นตอน (Two-Tier Approval Workflow):**
  1. **ฝ่ายวิชาการ (Academic):** ตรวจสอบวัตถุประสงค์และอนุมัติคำขอ (Approve/Reject)
  2. **ฝ่ายอาคารสถานที่ (Building Staff):** ตรวจสอบความพร้อมและยืนยันเปิดใช้งานห้อง (Mark Ready)
- 🚪 **จัดการสถานะห้องเรียน:** ปรับสถานะห้องเป็น "พร้อมใช้งาน" หรือ "ปิดปรับปรุงชั่วคราว"
- 👥 **ระบบจัดการรายชื่อผู้ใช้และสิทธิ์การเข้าถึง:** แยกระดับสิทธิ์ชัดเจนระหว่าง นักศึกษา, ฝ่ายวิชาการ, ฝ่ายอาคารฯ และ Admin

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Installation & Setup)

### วิธีที่ 1: รันด้วย `start_server.bat` (ง่ายและเร็วที่สุด)
1. เปิดโปรแกรม XAMPP แล้วกดปุ่ม **Start** ที่โมดูล **MySQL**
2. ดับเบิลคลิกที่ไฟล์ `start_server.bat`
3. ระบบจะเปิดบราวเซอร์ไปยัง `http://localhost:8000/public/` โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน Apache ใน XAMPP
1. วางโฟลเดอร์โปรเจกต์ไว้ที่ `C:\xampp\htdocs\projcet008-0036-main`
2. เปิดโปรแกรม XAMPP กด **Start** ทั้ง **Apache** และ **MySQL**
3. สร้างฐานข้อมูลและนำเข้าข้อมูล โดยเลือกวิธีใดวิธีหนึ่ง:
   - **วิธีง่าย:** เปิดบราวเซอร์ไปที่ `http://localhost/projcet008-0036-main/setup_db.php`
   - **หรือวิธี phpMyAdmin:** นำเข้าไฟล์ `database.sql` ผ่านทาง `http://localhost/phpmyadmin/`
4. เข้าใช้งานระบบได้ที่:  
   `http://localhost/projcet008-0036-main/public/`

## 🛡️ มาตรการความปลอดภัยและคุณภาพของโค้ด (Code Quality & Security)
- **Prepared Statements (PDO):** ป้องกันการโจมตีประเภท SQL Injection 100%
- **Secure Password Hashing:** ใช้ฟังก์ชัน `password_hash()` มาตรฐาน BCRYPT ในการเข้ารหัสผ่าน
- **XSS Protection:** ป้องกัน Cross-Site Scripting ด้วย `htmlspecialchars()` ทุกจุดแสดงผล
- **Strict Role-based Authorization:** ตรวจสอบสิทธิ์ระดับ Session ทุกหน้าที่ต้องใช้สิทธิ์เจ้าหน้าที่/แอดมิน
